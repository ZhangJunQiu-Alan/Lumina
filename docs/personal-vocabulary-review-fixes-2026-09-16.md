# 个人词库与复习规则修复

日期：2026-09-16

## 就绪评估

本地实现覆盖三个指定问题。收藏、学习组、复习状态采用现有独立数据表，无数据库结构变更。

- **P0：页面访问不写入数据。** 移除个人词库挂载时的清理和历史迁移调用。旧清理 API 保持响应兼容，返回零变更；对应命令显示 `retired: true`，不访问数据库。
- **P0：收藏独立保留。** 收藏和导入不再要求记忆状态为新词，不创建或重置复习状态。标记掌握保留收藏；手动取消收藏仅删除收藏；手动移除个人学习组保留收藏、复习状态与答题历史。历史迁移命令只补充缺失收藏。
- **P0：复习按答案结果转移。** 答错不升级、不毕业，保留在到期队列；已经掌握的词答错也会退回待巩固。
- **P1：未完成组可分别继续。** 个人词库显示所有未完成个人组，按最近学习时间排序，保留原组名；显示总词数、当前轮次与本轮完成词数，点击继续调用已有恢复流程。标题可进入组详情。加载失败后可重试，启动期间阻止重复点击。

## 复习规则

以下为定期复习（`source=review`）。快答对为用时不超过 6 秒，慢答对为超过 6 秒。

| 之前状态 | 答错 | 慢答对 | 快答对 |
| --- | --- | --- | --- |
| 新词 | 待巩固 | 回忆较慢 | 回忆稳定 |
| 待巩固 | 待巩固 | 回忆较慢 | 回忆较慢 |
| 回忆较慢 | 待巩固 | 回忆较慢 | 回忆稳定 |
| 回忆稳定 | 待巩固 | 回忆较慢 | 累计正确至少 3 次时已掌握，否则保持回忆稳定 |
| 已掌握 | 待巩固 | 回忆较慢 | 已掌握 |

- 答错：下次复习时间取「原到期时间」和「本次答题时间」中较早者；没有原到期时间时使用本次答题时间。不会把未完成的错词排到未来。`interval_days` 为待巩固的基础间隔 1 天，实际到期以 `next_review_at` 为准。
- 答对：根据新状态分别安排 1 / 3 / 7 天后复习；已掌握不再安排定期复习。
- 沿用原有累计计数：累计正确次数为 `review_count - lapse_count`，包括第二、三轮的评估。本次必须快答对，且之前为回忆稳定，才允许自动进入已掌握。答错退回待巩固后，必须重新经过回忆较慢与回忆稳定，不能仅凭历史正确次数毕业；没有将旧的累计计数改称连续正确次数。
- 第二、三轮初次评估新词：答错进入待巩固，慢答对进入回忆较慢，快答对进入回忆稳定，分别安排 1 / 3 / 7 天。已有状态时，答错回到待巩固，慢答对至多保持回忆较慢，快答对保持原状态；这些练习不会推迟已有的更早到期时间。
- 手动标记“不认识”回到待巩固并保持到期；手动“已掌握”仍是用户主动决定，不受自动毕业门槛限制。
- 保留已有答题同步去重和过期请求保护；历史记录不会批量改写。

## 进度口径

- 第一轮按已确认的不同单词计数；第二、三轮按已通过的不同单词计数，错词重排不重复计算。
- “共 X 词”为整组总数；“本轮已完成 X/Y 词”为当前轮次的词数，已跳过的掌握词可能使两者不同。
- 使用数据库聚合计数，避免大组词数被默认查询上限截断；组列表分页读取。
- 无历史快照时显示进度暂不可用的说明，不推算百分比。兼容缺少第一轮确认字段的旧表结构。
