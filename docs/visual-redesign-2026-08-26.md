# Lumina 全站视觉审查与改版记录

日期：2026-08-26

## 设计方向

Lumina 采用“安静的学习观测台”作为统一方向：让用户优先看到今天要做什么、完成到哪里、下一步是什么。界面使用矿物纸背景、深墨文字和单一青绿色信号色；琥珀色只用于复习提醒，珊瑚色只用于错误或危险操作。

- 背景：`#F4F7F5`
- 主文字：`#142B36`
- 次文字：`#61737B`
- 主操作：`#0E8F88`
- 复习提醒：`#E6A43A`
- 错误提示：`#D86652`
- 字体：Inter + 中文系统无衬线；Lora 仅保留给英文词汇或编辑性内容
- 动效：180–240ms，支持 `prefers-reduced-motion`

## User Story 审查结果

### 作为首次访问者

原问题：首屏导航、地图、三块能力卡和长页面同时争夺注意力；页面仍宣传已关闭的雅思听力；演示数字容易被误解为真实用户数据。

改动：收敛颜色、阴影和圆角；只宣传当前开放的雅思学术阅读；演示统计改为占位符；移动端首屏形成“价值主张 → 三项能力 → 主操作”的单一路径。

### 作为登录用户

原问题：桌面导航只有图标，必须悬停才能确认含义；移动导航体积大；每页重复使用厚边框和果冻阴影，视觉层级依赖装饰而不是信息。

改动：桌面改为常驻文字导航，移动端改为轻量五项底栏；统一应用壳层、页面背景、卡片、按钮和状态色；当前页面用连续移动的浅青指示块表示。

### 作为今天准备学习的用户

原问题：首页重复展示品牌，指标、轨迹、插画、选择器和按钮权重接近；黄色主按钮与全站青绿色操作语义冲突。

改动：首页改成“今日学习 / 你的学习台”标题；压低装饰插画和零数据指标；学习步骤使用安静面板；主操作统一为青绿色。

### 作为雅思阅读学习者

原问题：关闭听力后，空状态仍提到听力；题库卡显示内部 PDF 源文件名；大量高饱和试题按钮造成视觉噪声。

改动：删除听力残留文案；隐藏内部源文件标签；统一阅读页面色彩和卡片层级，保留试题作为主要操作。

### 作为刚注册、尚无数据的用户

原问题：个人页绘制整套零值趋势图和 365 天热力图，信息量大但没有行动价值；登录页展示虚构的进度统计。

改动：个人页无数据时显示明确的首学提示，完成学习后才显示趋势与热力图；登录页移除虚构统计，只解释会同步哪些真实内容。

### 作为阅读隐私政策或条款的用户

原问题：每一节都被包成厚重卡片，阅读节奏被重复边框打断。

改动：改为窄栏文档布局，用标题、留白和细分隔线组织内容；移动端保持单列阅读。

### 作为调整学习偏好的用户

原问题：设置页延续米色、圆形图标和厚阴影，与其他页面的新视觉语言不一致。

改动：设置容器、标题、图标、分隔线、分段控件和开关统一到新的青绿/深墨系统，保留原有设置行为。

- 只允许清理 `ielts-listening-audio`。`word-audio` 是词汇发音与例句朗读缓存，不属于雅思听力清理范围。
