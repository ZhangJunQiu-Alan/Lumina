# IELTS Reading Private Source Files

Put Cambridge IELTS Academic Reading source PDFs here when importing content locally.

- Do not commit PDFs or extracted full text.
- Use `npm run import:ielts-reading -- --pdf content/ielts-reading/raw/<file>.pdf --book <number> --dry-run`.
- Review the generated report under `output/ielts-reading/` before using `--apply`.
