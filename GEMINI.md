## 2. Visual Identity & UI Standards
- **Style**: Apple/Linear aesthetic. Minimalist, modern, and high-contrast.
- **Layout**: Bento Grid for feature showcasing.
- **Components**: Use `.glass` for frosted glass effects, large rounded corners (`32px`+), and subtle Shimmer animations for loading.
- **Interactions**: Prefer soft fades and 6px-offset floating entries over bouncy or fast animations.

## 3. Core Learning Philosophy
Lumina is a **State-Driven** system. Never simplify its SRS logic to binary "right/wrong" tracking. Always respect the 5 memory states: `new`, `fuzzy`, `slow_recall`, `stable_recall`, `mastered`.
